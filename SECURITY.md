# Security

Follow the [Shopvento UI security policy](https://github.com/shopventoapp/ui/blob/main/SECURITY.md) to report vulnerabilities privately. Include the starter and package versions, the affected route and a reproduction with synthetic data. Do not publish credentials, customer information or exploitable details in an issue.

The backend enforces authentication, authorization and payment status. This starter is responsible for its first-party proxy, host theme and routing. Deploy the current supported package release and use HTTPS for public storefronts.
