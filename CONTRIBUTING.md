# Contributing

Use Bun, TypeScript and English source/documentation. Customer-facing copy is German with capitalized Du, Dir and Dich. Use a fictional installation and synthetic fixtures in public contributions.

Keep booking, voucher, cart, checkout and account behavior in the published `@shopvento/ui` package. Discuss missing package capabilities upstream instead of copying or patching package logic here. Host changes should stay limited to composition, theme, content, routes and transport.

Run the commands in the README's checks table before submitting a pull request. Describe the customer-visible change and its validation. Never commit environment files, credentials, personal data or private installation names/domains. Add every new CLI script to the README in the same change.
